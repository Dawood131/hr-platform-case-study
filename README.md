# Connect Job | HR Recruitment Platform

Case study of a complete recruitment platform built from scratch as the sole frontend developer.

## Key Features

- Job postings and applications
- Interview scheduling
- Talent rating
- Job-linked messaging
- Standalone professional networking module
- Role-based access across multiple companies
- English and French localization

## My Role

Sole frontend developer: architecture, UI, state management, and API integration with the backend team.

## Tech Stack

`React` `Redux Toolkit` `React Query` `i18next` `Tailwind CSS`
